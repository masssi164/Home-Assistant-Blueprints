# Sicherheits- und Datenschutzmeldungen

Keine Tokens, Client-Secrets, vollständigen Traces mit persönlichen IDs oder private
Home-Assistant-Konfigurationen öffentlich einstellen. Ein vermutetes Problem zunächst
nur ohne ausnutzbare/identifizierende Details melden. Falls im veröffentlichten
Repository Private Vulnerability Reporting aktiviert ist, diesen privaten Weg nutzen;
diese Vorabfassung behauptet nicht, dass die Einstellung bereits aktiviert wurde.

Die Skripte steuern ein Gerät mit heißen Flüssigkeiten. Sie ergänzen weder eine
physische Sicherheitsverriegelung noch eine Tassenerkennung. Bei unklarer Cloud-Antwort
am Gerät prüfen, bevor erneut gestartet wird. Home Assistant und Agentenzugriffe
nicht ungeschützt öffentlich erreichbar machen.
